📋 資料集選擇指引

▶

在 GEO 搜尋新資料集前，確認以下條件可大幅提升 circRNA 分析品質與 DE 顯著性。

✅ 必要條件 Checklist
  • ✅Read length ≥ 100 bp PE（BSJ 偵測需跨 back-splice junction）
  • ✅Total RNA（rRNA-depleted），非 poly-A selection
  • ✅每組 ≥ 3 replicates（建議 ≥ 5 以通過 FDR 校正）
  • ✅明確 case vs. control（tumor/normal、treatment/vehicle）
  • ⚠️定序深度 ≥ 50 M reads/sample（<30M 偵測力明顯下降）
  • ⚠️組織樣本優先（cell line circRNA 較少，biomarker 轉化性低）
📊 關鍵因子速查
因子✅ 推薦⚠️ 可接受❌ 避免
Read length ≥ 150 bp PE 75–100 bp PE 50 bp PE（DCC 幾乎失效，需 adaptive fallback）
RNA-seq 方式 Total RNA（rRNA-depleted） RNase R enriched（circRNA 超富集） poly-A selection（circRNA ≈ 0）
樣本類型 組織（tumor vs. normal） 細胞株 KO/OE（機制研究） 細胞株藥物處理（circRNA 變化極少）
樣本數 ≥ 5 vs. 5（FDR 校正有效） 3 vs. 3（需用 nominal p-value） < 3 per group（統計功率不足）
設計 配對（同患者 tumor+normal） 獨立樣本 —
💡 已分析資料集： GSE113230（TNBC，150bp，9,349 circRNAs，482 DE，✅ 最佳示範）・ GSE58135（乳癌，50bp，⚠️ DCC 失效→ adaptive fallback，1,607 circRNAs）・ GSE323364（TNBC 細胞株，150bp，⚠️ 藥物處理 DE 極少）・ GSE133998（乳癌，150bp，配對設計，10,979 circRNAs，✅ 樣本最多）
GEO 查詢方法：Series 頁面 → Library Strategy（確認非 AMPLICON）、Library Selection（確認非 POLY_A）、 SRA run info 的 avgLength 欄（read length）、spots 欄（PE: spots×2 = total reads）
使用教學

📖 Pipeline 使用教學

▶

從選擇資料集到解讀報告，以下教學涵蓋完整分析流程與結果解讀說明。

點擊圖片可放大
1

選擇適合的 GEO 資料集

在 NCBI GEO 搜尋 circRNA 相關研究。 找到目標 Series 後，確認以下三項關鍵欄位：

Library Strategy
RNA-Seq（非 miRNA-Seq / ChIP-Seq）
Library Selection
TOTAL 或 other（rRNA-depleted）；避免 POLY_A
avgLength（SRA RunInfo）
≥ 100 bp（150 bp PE 最佳）
💡 點開上方「資料集選擇指引」可查看詳細因子評分表與已測試資料集清單。
2

設定分析參數（Step 1–3）

在頁面下方的 Step 1–3 表單依序設定：

Step 1 — 偵測工具
預設選 CIRIquant + DCC（共識模式）；讀長 ≤ 75 bp 時只勾 CIRIquant。 勾選「Adaptive fallback」可在工具偵測數嚴重失衡時自動降為單工具。
Step 2 — DE 方法
三種方法（edgeR / DESeq2 / limma-voom）固定全跑； 選「報告主方法」決定報告預設顯示哪種結果。 小樣本（n=3）建議選 edgeR_ciriquant 或 limma-voom。
Step 3 — 進階參數
min BSJ reads（過濾雜訊）、FDR / log2FC 閾值；一般保持預設即可。
ℹ️ 設定完成後點「儲存設定」可先存下來，之後再決定是否執行。
3

啟動分析

共三種啟動方式，依資料來源選擇：

方式一：GEO 一鍵啟動
輸入 GSE ID（如 GSE113230），點「🚀 一鍵啟動」。 系統自動從 SRA 下載資料並執行完整 pipeline。適合大多數情況。
方式二：手動 SRR 清單
適合從大型資料集中選取特定樣本，或需要自訂 condition 標籤（tumor/normal 等）。 可逐筆填入或上傳 CSV（格式：srr_id,condition）。
方式三：本地 FASTQ
Server 上已有 FASTQ 檔時，指定目錄路徑。系統自動偵測配對（支援 _1/_2、_R1/_R2 等格式）， 建立 symlink 後直接從 QC 步驟開始，略過下載。
⚠️ 啟動後請勿重新整理或關閉分析設定頁，改用「監控進度」頁追蹤狀態。
4

監控執行進度

啟動後點「查看執行狀態」或輸入任務編號（格式 GSE113230-XXXX）進入狀態頁。

下載 SRA→ FastQC→ fastp 修剪→ CIRIquant→ STAR ×3→ DCC→ 共識過濾→ DE 分析→ 報告生成
CIRIquant
耗時最長（NFS 環境約 2–4 小時/樣本）；同時最多跑 3 個
DCC
需 STAR mate1/mate2 完成才能執行；約 15–30 分/樣本
DE + 報告
全部 circRNA 偵測完成後約需 10–20 分鐘
💡 狀態頁每 5 秒自動更新。Web UI 重啟後仍可正確推斷已完成步驟。
5

下載並解讀報告

所有步驟完成後，狀態頁頂部出現「📥 下載報告」與「🔗 在線瀏覽」按鈕。

report.html
自包含單一 HTML 檔，可離線開啟，含所有互動式圖表
count_matrix.tsv
BSJ count 矩陣，可用於自訂下游分析
de_results.tsv
三種 DE 方法的完整結果（logFC、p-value、Type）
ℹ️ 切換到「📊 報告解讀」頁籤，了解報告各區塊的意義與解讀重點。
① Summary 統計方塊 & DE 方法切換

報告頂部顯示四個統計方塊（Total circRNAs / Significant / Up / Down）和三個方法切換按鈕。

Total circRNAs
通過共識過濾、進入 DE 分析的 circRNA 總數（含低表達過濾後）
Significant
|log2FC| ≥ 設定閾值（預設 1.0）且 p-value < 0.05 的 circRNA 數
edgeR_ciriquant
主方法；BSJ/FSJ ratio 測試，區分 Type I/II；小樣本首選
DESeq2
BSJ count Wald test；poscounts 正規化，避開全零問題；較保守
limma-voom
TMM + voom weights；稀疏計數最穩健；偵測到的 DE 數最多
💡 三種方法切換時，Volcano 圖、Heatmap、Top DE 表格、Biomarker 表格全部同步更新，不需重新載入頁面。
② Venn Diagram — 三方法交集

三個圓分別代表三種 DE 方法偵測到的顯著 circRNA 集合。點擊任意區域可看對應 circRNA 清單。

三圓交集（中心）
三種方法均顯著，最可靠的 DE circRNA，優先關注
僅一圓
方法特異性結果；edgeR 獨有的通常是 FSJ ratio 效果；limma 獨有的多是低豐度
交集 > 60%
三方法高度一致，表示 DE 結果穩健；小樣本 (n=3) 通常交集較低
③ Type I / II 分類（edgeR_ciriquant 專屬）

edgeR_ciriquant 透過 BSJ/FSJ ratio 測試，可區分 circRNA 的調控模式：

Type I circRNA 特異性調控：BSJ count ratio 改變，FSJ（線性轉錄本）不變。 環化效率真正改變，是 circRNA biomarker 研究的主要目標。典型比例 85–97%。
Type II 兩層同時調控：BSJ ratio 顯著且 FSJ 獨立也顯著。circRNA + parent gene 同步改變。
Type III / NS FSJ 顯著但 BSJ 不顯著，或統計未達閾值。不計入顯著 DE。
ℹ️ 高 Type I 比例（>80%）表示分析找到的是 circRNA 專一性調控，臨床生物標記潛力較高。
④ Biomarker 候選表

對顯著 DE circRNA 計算六維 composite score，由高到低排列 Top 30。

sig_norm
−log10(p-value)，越顯著分數越高（上限 10）
fc_norm
|log2FC|，效應量越大分數越高（上限 5）
conf_norm
共識 confidence score：log2(BSJ+1) × 座標一致性，越高越可靠
known_bonus
在 circBase 資料庫中有記錄 → +1（已知 circRNA）
mirna_norm
distinct miRNA sponge binding 數（來自 CircInteractome/ENCORI）
rbp_norm
distinct RBP binding 數（來自 CircInteractome/ENCORI）
💡 點擊任意 circ_id 可開啟詳細 modal，查看 miRNA sponge、RBP binding site、mini Volcano 與 Heatmap。
⑤ circRNA 詳細 Modal — Circular Structure & Interaction

點擊任意 circ_id 開啟詳細視窗，包含四個分頁：

⬛ Circular Structure
環狀圖顯示 exon 結構；外圈 badge = miRNA binding site；內圈 = RBP binding site。 點擊 badge 可展開/收起對應 binding，顯示 binding 序列與位置。可下載 SVG。
📺 miRNA Sponge
所有 miRNA binding site 列表，含 Priority Score（8mer seed +4、CLIP evidence +3、已知 circBase +1）。 Binding Seq 欄自動從 UCSC hg19 API 取得結合序列。可排序、下載 CSV。
🧬 RBP Binding
RBP binding site 列表，Priority Score 含 CLIP evidence、ENCORI 支援、in_circ 分類。
📈 Volcano / 🔥 Heatmap
Mini 互動圖表，標示該 circRNA 在全局中的位置；可下載 PNG。
ℹ️ miRNA 和 RBP 資料來自 CircInteractome 與 ENCORI（各取 top-50 up/down 聯集，約 150–250 個 circRNA）。無 interaction data 的 circRNA 對應欄位顯示「—」。
⑥ Heatmap & Volcano 操作技巧
Heatmap Top-N 控制
預設顯示 10 up + 10 down；可調整至最高 50+50。Tumor 欄在左（紅色），Normal 在右（綠色）
Volcano 標記開關
右上角「Heatmap circles: ON/OFF」切換 Heatmap 前 N 個 circRNA 在 Volcano 上的標記
圖表下載
Plotly 圖表右上角浮動工具列可下載 PNG；各表格右上角「⬇ CSV」可匯出資料
列印 / 存 PDF
頁面頂部「🖨 列印」按鈕，支援 @media print 排版（圖表不跨頁，表格從新頁開始）
